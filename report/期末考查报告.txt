第1章 考查题目与要求

================================================================================

1.1 题目名称

掌上约球——校园球友召集平台

1.2 主要功能

本项目为一个面向校园和社区的球友召集平台移动Web应用，主要功能如下：

【用户系统】
- 用户注册（账号密码、手机号、常住地、球类兴趣）
- 用户登录（JWT token 认证）
- 个人信息管理（头像上传、资料编辑、密码修改、退出登录）

【邀约功能】
- 发起邀约（选择球类、时间、地点、人数，支持高德地图选点）
- 管理邀约状态（等待中/已召集/已终止）
- 终止邀约、删除邀约
- 查看参与人信息（手机号中间4位脱敏显示）

【附近约球】
- 基于浏览器定位获取当前位置
- 按距离/时间排序展示附近邀约列表
- 按球类筛选邀约
- 加入邀约/退出邀约

【我的邀约】
- 查看我发起的邀约
- 查看我参与的邀约

1.3 技术要求

- 前端：Vue 3 + Vant 4 组件库，移动端H5界面
- 后端：Go 语言 + Gin 框架
- 数据库：SQLite
- 前后端分离架构，RESTful API 通信
