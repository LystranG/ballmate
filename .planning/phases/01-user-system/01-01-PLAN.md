<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 浏览器→后端 API | 用户输入（账号、密码、手机号）跨越此边界，属于不可信输入 |
| 后端→SQLite | SQL 查询通过 GORM ORM 执行，参数化查询防注入 |
| 后端→文件系统 | 头像文件名由服务端生成（时间戳），不使用用户提供的文件名 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | POST /api/v1/auth/login | mitigate | bcrypt.CompareHashAndPassword 验证密码，不使用 == 比较 |
| T-01-02 | Tampering | JWT token | mitigate | HMAC-SHA256 签名，ParseToken 验证签名有效性 |
| T-01-03 | Information Disclosure | User.Password 字段 | mitigate | Password 字段 json:"-" 标签，不序列化到响应 |
| T-01-04 | Tampering | 用户输入（账号、手机号） | mitigate | 后端 handler 校验 phone 正则 `^\d{11}$`，GORM 参数化查询防 SQL 注入 |
| T-01-05 | Information Disclosure | JWT payload | accept | payload 仅含 user_id 和 exp，无敏感数据，风险可接受 |
| T-01-06 | Denial of Service | SQLite 并发写入 | mitigate | db.SetMaxOpenConns(1) 防止并发锁错误 |
| T-01-SC | Tampering | npm/go 包安装 | mitigate | 所有包标记为 [ASSUMED]，均为生态主流库，版本已在 RESEARCH.md 中固定 |
</threat_model>
