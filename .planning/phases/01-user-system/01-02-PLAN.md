    service/user.go：实现以下函数：
    - GetProfile(userID uint) (*model.User, error)：GORM First 查询，返回 User 指针
    - UpdateProfile(userID uint, nickname, location, sports string) (*model.User, error)：GORM Updates 更新 Nickname/Location/Sports 字段，返回更新后的 User
    - UpdatePassword(userID uint, oldPassword, newPassword string) error：先 GetProfile 获取用户，CheckPassword 验证旧密码（失败返回 "原密码错误" 错误），SetPassword 设置新密码，GORM Save 保存
    - UpdateAvatar(userID uint, avatarPath string) (*model.User, error)：GORM Updates Avatar 字段，返回更新后的 User

    handler/user.go：实现以下 handler：
    - GetProfile：从 c.GetUint("userID") 获取 userID，调用 service.GetProfile，Success 返回 user 对象（Password 字段因 json:"-" 自动排除）
    - UpdateProfile：绑定 JSON body（nickname, location, sports 均为可选字符串），调用 service.UpdateProfile，Success 返回更新后的 user
    - UpdatePassword：绑定 JSON body（oldPassword, newPassword, confirmPassword），校验 newPassword == confirmPassword（不一致返回 400 "两次密码输入不一致"），调用 service.UpdatePassword，成功返回 Success(c, nil)
    - UploadAvatar：按 RESEARCH.md Pattern 6，c.FormFile("avatar") 获取文件，beforeRead 校验：文件扩展名必须在 [.jpg, .jpeg, .png, .gif] 中（filepath.Ext 转小写后判断），文件大小不超过 5MB（file.Size <= 5*1024*1024）；生成唯一文件名（fmt.Sprintf("%d%s", time.Now().UnixNano(), ext)），c.SaveUploadedFile 保存到 uploads/ 目录；调用 service.UpdateAvatar 更新数据库，Success 返回 {avatar: "/uploads/"+filename}

    在 router/router.go 中将 /user/profile GET/PUT、/user/password PUT、/user/avatar POST 的占位 handler 替换为 handler.GetProfile、handler.UpdateProfile、handler.UpdatePassword、handler.UploadAvatar。

    在 main.go 中设置 Gin 的 MaxMultipartMemory 为 8MB（r.MaxMultipartMemory = 8 << 20）。

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 浏览器→后端 API | 用户上传的头像文件和资料更新数据属于不可信输入 |
| 后端→文件系统 | 头像文件写入 uploads/ 目录，文件名由服务端生成 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | GET /api/v1/user/profile | mitigate | User.Password 字段 json:"-" 确保不序列化到响应 |
| T-02-02 | Tampering | PUT /api/v1/user/password | mitigate | service.UpdatePassword 先 CheckPassword 验证旧密码，bcrypt 比较 |
| T-02-03 | Information Disclosure | 文件上传路径遍历 | mitigate | 使用 time.Now().UnixNano() 生成文件名，不使用用户提供的原始文件名；filepath.Ext 仅取扩展名 |
| T-02-04 | Denial of Service | 大文件上传 | mitigate | 前端 beforeRead 校验 5MB + 后端 MaxMultipartMemory=8MB 双重限制 |
| T-02-05 | Tampering | 修改他人资料 | mitigate | 所有 user handler 从 JWT 中间件的 c.GetUint("userID") 获取用户 ID，不接受客户端传入的 userID |
| T-02-SC | Tampering | npm/go 包安装 | mitigate | 本 plan 不新增依赖，复用 Plan 01 已安装的包 |
</threat_model>
