# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Vant 4 (ConfigProvider + CSS Variables) |
| Preset | Vant 4 default theme, primary color override to #1989fa |
| Component library | Vant 4.9.24 |
| Icon library | Vant built-in icons (van-icon) |
| Font | System font stack (-apple-system, BlinkMacSystemFont, sans-serif) |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline element spacing |
| sm | 8px | Compact element spacing, tag gaps |
| md | 12px | Form field internal padding |
| lg | 16px | Default section padding, card padding |
| xl | 24px | Section gaps between form groups |
| 2xl | 32px | Page top/bottom padding |
| 3xl | 48px | Bottom navigation clearance |

Exceptions: Bottom TabBar height 50px (Vant default). Touch targets minimum 44px height.

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 14px | 400 (regular) | 1.4 |
| Heading | 18px | 600 (semibold) | 1.3 |
| Display | 24px | 600 (semibold) | 1.2 |

Font family: Vant default system stack (inherits device system font for optimal mobile rendering).

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff | Page background, form backgrounds |
| Secondary (30%) | #f7f8fa | Section backgrounds, profile header bg, disabled states |
| Accent (10%) | #1989fa | Primary buttons, active tab bar icon, links |
| Destructive | #ee0a24 | Logout button, delete account (if any), error text |

Accent reserved for:
- Primary action buttons (登录, 注册, 保存)
- Active bottom tab bar icon + label
- Text links (跳转注册/跳转登录)
- Form field focus border

## Interaction Patterns

| Pattern | Implementation | Notes |
|---------|---------------|-------|
| Form submission | Button loading state + disable during request | Prevent double-submit |
| Success feedback | van-toast (showToast) | 1500ms duration |
| Error feedback | van-toast (showToast) | 2000ms duration |
| Destructive confirm | van-dialog (showConfirmDialog) | Confirm + Cancel buttons |
| Navigation back | van-nav-bar left arrow | router.back() |
| Pull to refresh | Not needed for Phase 1 | Static form pages |
| Skeleton loading | Not needed for Phase 1 | Profile data loads fast |
