## Interaction Contracts

### 发起邀约表单

| Interaction | Behavior |
|-------------|----------|
| Sport type selection | Single-select among Tag list. Selected tag: `type="primary"`. Unselected: `plain`. Tap to toggle. |
| DateTime field tap | Opens `van-popup position="bottom"` with PickerGroup. Min date = today. Confirm writes formatted string to field. |
| Location field tap | Navigates to map picker view (or opens full-screen popup). User taps map to place marker. Geocoder resolves address. Confirm returns to form with address filled. |
| Capacity selection | Single-select among [2人, 4人, 6人, 8人, 10人] Tag list. Same visual pattern as sport type. |
| Form submit | Validates all 4 fields non-empty. Shows loading on button. On success: toast + navigate to detail page. On failure: toast error. |
| Back navigation | NavBar left-arrow calls `router.back()`. No confirmation needed (form data loss is acceptable for MVP). |

### 邀约详情页

| Interaction | Behavior |
|-------------|----------|
| Load | Fetch invitation detail by ID. Show loading skeleton or spinner during fetch. |
| Terminate button | Only visible when `status == "waiting"` AND current user is creator. Tap triggers `showConfirmDialog`. On confirm: API call, toast, refresh status. |
| Delete button | Only visible when `status == "terminated"` AND current user is creator. Tap triggers `showConfirmDialog`. On confirm: API call, toast, navigate back. |
| Participant list | Only rendered when current user is creator (D-10). Shows each participant as van-cell with nickname + masked phone. |
| Status display | Computed from API response. Badge color per status table. Non-interactive. |

### 地图选点组件

| Interaction | Behavior |
|-------------|----------|
| Map load | Initialize AMap at zoom 14, centered on user's approximate location (or city center fallback). |
| Map tap | Place/move marker at tap point. Reverse geocode to get address string. Display address below map in readonly field. |
| Confirm | Emit `{ longitude, latitude, address }` to parent form. Close map view. |
| Cancel | Discard selection, return to form with previous value (or empty). |
