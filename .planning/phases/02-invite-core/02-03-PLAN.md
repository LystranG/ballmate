  <action>
    创建 frontend/src/views/invitation/detail.vue（同时创建 frontend/src/views/invitation/ 目录）。

    使用 script setup。导入：getInvitation, terminateInvitation, deleteInvitation, getParticipants from '@/api/invitation'；useUserStore from '@/stores/user'；useRoute, useRouter from 'vue-router'；showToast, showConfirmDialog from 'vant'；ref, computed, onMounted from 'vue'。

    响应式数据：invitation（ref(null)），participants（ref([])），loading（ref(true)），actionLoading（ref(false)）。

    computed isCreator：invitation.value && userStore.userInfo && invitation.value.creator_id === userStore.userInfo.id。

    computed statusConfig：根据 invitation.value.status 返回 { label, bgColor, textColor }，映射关系：waiting→{label:'等待中', bgColor:'#fffbe8', textColor:'#ed6a0c'}，gathered→{label:'已召集', bgColor:'#e8f7e8', textColor:'#07c160'}，terminated→{label:'已终止', bgColor:'#f5f5f5', textColor:'#969799'}，expired→{label:'已过期', bgColor:'#f5f5f5', textColor:'#969799'}。

    computed formattedTime：将 invitation.value.activity_time 格式化为 "MM月DD日 HH:mm"（per UI-SPEC Copywriting Contract）。

    onMounted：调用 loadDetail()。

    loadDetail 函数：调用 getInvitation(route.params.id)，将 response.data 赋值给 invitation.value；若 isCreator.value 为 true，再调用 getParticipants(route.params.id)，将 response.data 赋值给 participants.value；finally 设 loading = false。

    onTerminate 函数：调用 showConfirmDialog({ title: '终止邀约', message: '确定要终止这个邀约吗？终止后参与人将无法继续加入。' })，确认后设 actionLoading = true，调用 terminateInvitation(route.params.id)，成功后 showToast('已终止') 并重新调用 loadDetail()，失败时 showToast 错误信息，finally 设 actionLoading = false。

    onDelete 函数：调用 showConfirmDialog({ title: '删除邀约', message: '确定要删除这个邀约吗？删除后将不再显示。' })，确认后设 actionLoading = true，调用 deleteInvitation(route.params.id)，成功后 showToast('已删除') 并 router.back()，失败时 showToast 错误信息，finally 设 actionLoading = false。

    模板结构（per UI-SPEC Screen 2 布局）：
    - van-nav-bar title="邀约详情" left-arrow @click-left="router.back()"
    - 加载中：van-loading（v-if="loading"，居中）
    - 内容区（v-else-if="invitation"）：
      - 状态徽章区域（NavBar 下方）：van-tag size="medium" :style="{ background: statusConfig.bgColor, color: statusConfig.textColor }" 显示 statusConfig.label
      - van-cell-group inset（邀约信息）：
        - van-cell title="球类" :value="invitation.sport_type"
        - van-cell title="活动时间" :value="formattedTime"
        - van-cell title="活动地点" :value="invitation.address"
        - van-cell title="参与人数" :value="`${invitation.participant_count}/${invitation.max_people}人`"，当 participant_count/max_people > 0.5 时 value 文字颜色 #1989fa
      - 参与人列表（v-if="isCreator && participants.length > 0"）：van-cell-group inset title="参与人"，遍历 participants，每项 van-cell :title="p.nickname" :value="p.phone"
      - 参与人为空时（v-if="isCreator && participants.length === 0 && invitation.status !== 'waiting'"）：van-empty description="暂无参与人"
      - 操作按钮区域（padding: 24px 16px）：
        - 终止按钮（v-if="isCreator && invitation.status === 'waiting'"）：van-button type="danger" plain block round :loading="actionLoading" @click="onTerminate" 文字"终止邀约"
        - 删除按钮（v-if="isCreator && invitation.status === 'terminated'"）：van-button type="danger" block round :loading="actionLoading" @click="onDelete" 文字"删除邀约"
    - 加载失败（v-else）：van-empty description="加载失败，请下拉刷新"

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 前端→后端 | 终止/删除操作携带 JWT，后端校验创建者身份 |
| 前端渲染 | 参与人列表仅在 isCreator 为 true 时渲染，防止 UI 层信息泄露 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | Information Disclosure | 参与人手机号前端展示 | mitigate | 后端已脱敏（per D-09），前端直接展示 138****5678 格式，无完整手机号到达前端 |
| T-02-10 | Spoofing | 非创建者查看参与人列表 | mitigate | 双重防护：前端 isCreator computed 控制渲染；后端 GetParticipants 校验 creator_id == userID（per D-10） |
| T-02-11 | Tampering | 非创建者触发终止/删除 | mitigate | 前端按钮仅在 isCreator 时渲染；后端 TerminateInvitation/DeleteInvitation 校验 creator_id（per D-07） |
</threat_model>
