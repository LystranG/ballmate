    定义 InvitationResponse 结构体，包含 Invitation 所有字段 + Status string（计算后）+ ParticipantCount int。

    实现 computeStatus(inv model.Invitation) string：若 inv.Status == "waiting" 且 inv.ActivityTime.Before(time.Now()) 则返回 "expired"，否则返回 inv.Status。所有返回邀约数据的函数都调用此方法（per Pitfall 3）。

    实现 CreateInvitation(creatorID uint, sportType, address string, activityTime time.Time, latitude, longitude float64, maxPeople int) (*InvitationResponse, error)：创建 Invitation 记录，Status 默认 "waiting"（由 GORM default tag 处理），创建者自动加入 participations 表（计入人数，per RESEARCH.md Open Questions 建议），然后检查 count >= maxPeople 自动更新 status 为 "gathered"（边界情况：maxPeople=1 时创建即召集）。

    实现 GetInvitation(id uint) (*InvitationResponse, error)：查询邀约，调用 computeStatus，查询 participations count，返回 InvitationResponse。

    实现 TerminateInvitation(id, userID uint) error：查询邀约，校验 CreatorID == userID（否则返回 "无权操作"），校验 computeStatus 为 "waiting"（否则返回 "只有等待中的邀约可以终止"），更新 Status 为 "terminated"。

    实现 DeleteInvitation(id, userID uint) error：查询邀约，校验 CreatorID == userID，校验 Status == "terminated"（否则返回 "只有已终止的邀约可以删除"），软删除邀约（DB.Delete），同时软删除对应 participations（DB.Where("invitation_id = ?", id).Delete(&model.Participation{})，per Pitfall 5）。

    实现 GetParticipants(id, userID uint) ([]ParticipantInfo, error)：校验 CreatorID == userID（否则返回 "无权查看"），JOIN participations + users 查询 nickname 和 phone，调用 maskPhone 脱敏后返回（per D-09, D-10）。

    实现 maskPhone(phone string) string：len != 11 时原样返回，否则返回 phone[:3] + "****" + phone[7:]。

    - GET "/:id/participants" → handler.GetParticipants

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | PUT /invitations/:id/terminate | mitigate | service.TerminateInvitation 校验 CreatorID == userID，非创建者返回 403 |
| T-02-02 | Spoofing | DELETE /invitations/:id | mitigate | service.DeleteInvitation 校验 CreatorID == userID，非创建者返回 403 |
| T-02-03 | Information Disclosure | GET /invitations/:id/participants | mitigate | service.GetParticipants 校验 CreatorID == userID（per D-10），非创建者返回 403；手机号后端脱敏（per D-09） |
| T-02-04 | Tampering | POST /invitations（状态篡改） | mitigate | Status 字段由后端 GORM default 设置为 "waiting"，前端不传 status 字段，handler 不接受 status 参数 |
