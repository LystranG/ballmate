    1. 实现 JoinInvitation(invitationID, userID uint) error：
       - DB.First 查询邀约，不存在返回 "邀约不存在"
       - computeStatus 校验状态必须为 "waiting"，否则返回 "该邀约已无法加入"
       - COUNT participations 校验未满员，否则返回 "邀约人数已满"
       - DB.Create participation 记录（联合唯一索引自动防重复，Create 失败返回 "您已加入该邀约"）
       - 加入后重新 COUNT，如果 count >= maxPeople 则 Update status 为 "gathered"（满员自动状态流转）

    2. 实现 LeaveInvitation(invitationID, userID uint) error：
       - DB.First 查询邀约，不存在返回 "邀约不存在"
       - 校验 CreatorID != userID，创建者不能退出自己的邀约
       - computeStatus 校验状态为 "waiting"，否则返回 "该邀约状态不允许退出"
       - DB.Where(...).Delete participation，RowsAffected == 0 返回 "您未加入该邀约"
       - 如果邀约之前是 "gathered" 状态（有人退出后不再满员），恢复为 "waiting"

    3. 修改 GetInvitation 函数签名为 GetInvitation(id, userID uint)，新增返回字段 HasJoined bool：
       - 在 InvitationResponse 中新增 HasJoined bool json:"has_joined"
       - buildResponse 不变，GetInvitation 额外查询 participation 表判断当前用户是否已加入
       - 注意：同时修改 handler.GetInvitation 传入 userID

    在 backend/handler/invitation.go 中新增：

    4. 实现 JoinInvitation(c *gin.Context)：c.GetUint("userID")，解析 :id 参数，调用 service.JoinInvitation，成功返回 Success(c, nil)，失败根据错误信息返回 400 或 403。

    5. 实现 LeaveInvitation(c *gin.Context)：c.GetUint("userID")，解析 :id 参数，调用 service.LeaveInvitation，成功返回 Success(c, nil)，失败返回 400 或 403。

    6. 修改 GetInvitation handler：从 c.GetUint("userID") 获取 userID，传给 service.GetInvitation(uint(id), userID)。
